# Select

A single-choice dropdown on Base UI Select with a Radix-shaped API (`onValueChange(value: string)`). From `@pts/ui/select`.

**Parts:** `Select`, `SelectTrigger` (`size="sm" | "default"`: h-8 / h-9), `SelectValue` (placeholder in `muted-foreground`), `SelectContent`, `SelectGroup`, `SelectLabel` (text-xs muted), `SelectItem`, `SelectSeparator`.

**Look:** trigger matches Input (border-input, shadow-xs, rounded-md, ChevronDown at 50%). Popup: `bg-popover border rounded-md shadow-popover p-1`, at least the trigger's width. Items: `rounded-sm py-1.5 pl-2 pr-8 text-sm`, Check indicator on the right.

**Rules**

- The popup is left-aligned with its trigger by default (`align='start'` in the wrapper). Never pass `align='start'` at a call site; pass another `align` only when deviating on purpose. (guard: eslint `pts/no-align-start`)
- Items need `hover:bg-accent hover:text-accent-foreground` alongside `data-highlighted:` — Base UI doesn't set `data-highlighted` on plain mouse hover. The wrapper already does; keep both if you restyle. (guard: review)
- Inside a sheet, a Select change is a form value applied on Save, never an immediate mutation. (guard: review)
- **An "Add …" picker hangs from its button.** A `SearchableCombobox` with a custom `trigger` (the + / Add button at the right of a section heading: Members, People, repositories) opens with its right edge on the button's, just below it, inside the content column; a field opens under its left edge. Option avatars carry a hairline ring so the circle shows on a highlighted row. (guard: review)
- **Entity picker fields.** A picker for an entity (person, company, client, project, task; originator and closer are a person; a picker that only lists sign-ins (assignee, project owner, member, "Log hours for") is a sign-in, `entity='user'`) leads its label with that entity's registry icon in its colour: `FormLabel entity='company'`, or `EntityFieldLabel` (`components/ui/entity-label-icon.tsx`) outside react-hook-form; an "Add …" picker's section title takes the same icon (`SheetSection icon`). The icon is `aria-hidden`, so the label still names the field. It sits in the line of text like a word, one word space before its name (`EntityLabelText`), never as a flex item spaced by the label's gap, so a label naming two entities spaces evenly. Inside the picker, a person shows their own avatar in each option and in the trigger: a sign-in passes `userId`, anyone else `avatar: { src: personPhotoSrc(…) }` (photo, else initials); never a generic person glyph. A picker whose options are all one entity (companies, clients, projects) shows no icon in its options or trigger: the label carries it. A one-off option ("Unassigned") may keep an icon. Sweep for them when you add a sheet or dialog. `/design#pickers`. (guard: review)
- For long or searchable lists use `SearchableCombobox` (`components/ui/searchable-combobox.tsx`). Its picked option has a check on the right; no row keeps a left gutter for it. List filters: `filter.md`. (guard: review)
- **A picked record shows as its card (trial, Nov 2026).** A picker holding a record (`EntityLinkPicker`, the task sheet's "Project or lead", the client field on the invoice, hour block and project sheets) passes `record` to `SearchableCombobox`: once picked, the field becomes that record's preview card (`PickedRecordCard`, `components/ui/picked-record-card.tsx`, built on `SheetRecordRow`): the entity's icon, its name and detail line, at exactly a field's height (36px, `SheetRecordRow size='field'`) so it lines up with the fields beside it when it is one line; a card with a detail line (an email, a lead's company) keeps the two-line card height. The whole card opens the record, stacked as its sheet; × clears it, on required fields too (the form's own check stops an empty save), and the up-down chevron opens the list again, under the card at its width. A read-only field keeps the card but drops × and the chevron. `PICKED_RECORD_CARDS = false` turns the trial off everywhere: the field comes back, ending in `OpenRecordButton` (`components/ui/open-record-button.tsx`), the outline icon button that stacks the record's sheet. Never a separate preview row under the field. One field picks between two record types when a record belongs to exactly one of them: its label names both, each icon right before its entity ("[icon] Project or [icon] Lead"), and once one is picked names only that one ("[icon] Lead"), its options carry each entity's icon, grouped by type (a group heading replaces any type prefix in the names), and picking one clears the other. (guard: review)
- **A picker opens on its selection.** The selected option is scrolled into the middle of the list, checked, and highlighted, so arrows and Enter start there; a multi-select opens on its first ticked option. It happens once per open: scrolling and hovering afterwards are left alone, and typing a search highlights the top match. A hand-built cmdk picker gets this from `useRevealSelected` in `components/ui/command.tsx` (its list `ref`, plus the same value as the `Command`'s `defaultValue`). (guard: review)
- **Search finds a record by what people remember.** Every cmdk picker searches with `scoreSearchMatch` (`lib/utils/search-match.ts`): each typed word must appear in the option's label or `keywords`, ranked exact, prefix, word start, then mid-word; below those, spacing slips ("warmintro") and one typo per word of 4+ letters (first letter fixed) still match. A company or client picker passes its current people ("Name · email") and live projects ("Name · project") as `matchHints` (`companySearchHintsSql`), so typing a contact's or project's name finds the company, and the one that matched shows under the company's name. (guard: review)
- Every floating panel (this list, popovers, menus, date pickers) uses `shadow-popover`. (guard: eslint `pts/popover-shadow`)
- **"When does this take effect" is `EffectiveMonthSelect`** (`components/billing/effective-month-select.tsx`): a tinted callout, title left, a `w-72` month select right, one optional note line. Billing starts/stops, billing type and commission changes, and a sign-in's role change all use it. Month labels come from `lib/billing/months.ts` (`monthLabel`, `monthLabelFromNow`, `currentMonthStartUtc`), counted in UTC like the server. (guard: review)
