# Board (kanban drag and drop)

The project task board, My Tasks and the lead board drag cards the same way, through one hook and one overlay.

**Code:** `useKanbanDrag` (`apps/internal/lib/dnd/use-kanban-drag.ts`) for drag state and drop targets, `BoardDragOverlay` and `BOARD_CARD_GHOST_CLASS` (`apps/internal/components/board/board-drag.tsx`) for what the person sees. Pure move logic is in `lib/dnd/kanban-draft.ts`, ranks in `lib/dnd/kanban.ts`.

- **The card moves while it is dragged.** Carrying a card into another column moves it there at once, so that column opens a gap the card's exact height and its cards slide aside; the column it left closes up. No placeholder pops in. (guard: review)
- **The dragged card's own slot is the drop target:** a dashed outline the card's height (`BOARD_CARD_GHOST_CLASS`). Where the outline is, the card lands. (guard: review)
- **The preview never changes size.** dnd-kit sizes the overlay to the card that was picked up; previews fill it (`w-full`), never a fixed width. On drop the preview glides into its slot (120ms). (guard: review)
- **The column the card is in** takes a faint fill (6%) in its own status hue while dragging (`boardColumnClass(hue, true)`), and no ring or outline. (guard: review)
- **A board sits in the page shell like a list.** Toolbar row (tabs, count, Create), then one `PagePanel` holding the `FilterBar` (search first, then the board's filters) and the board below it. The toolbar count reads "Showing N of M" while search or a filter narrows it, and a search that matches nothing shows "No tasks match the current filters." (or leads). (guard: review)
- **Columns are status lanes, not boxes.** `boardColumnClass` (`components/board/board-column.ts`): no fill or border, a 2px line across the top in the status badge's hue (`BOARD_LANE_TINTS`, from the same hue map as the badge: `TASK_STATUS_HUES`, `getLeadStatusHue`), a 1px divider between lanes, and 8px side padding so cards run close to the lane's width. Lines are muted (light 500 at 50%, dark the badge ink at 40%) so the badge leads. Every board lays lanes out the same way (`BOARD_GRID_CLASS`, `boardGridStyle`): one row capped at the board's height, each lane 20rem to 24rem (spare width beyond that stays empty, so cards never stretch). Cards (`card` + border + shadow) sit straight on the panel. (guard: review)
- **Search and filters run in the browser** when the board already holds what they narrow (Leads: search, source; My tasks: search; project board: search, person), through `useListParams` `shallowKeys`, so typing never reloads the page. A drag on a filtered board keeps the hidden cards' places: Leads ranks around them (`hiddenLeads`), My tasks maps the drop index with `shownIndexToBucketIndex` (`lib/dnd/shown-index.ts`). (guard: review)
- A new board uses `useKanbanDrag` and `BoardDragOverlay`; it renders `itemsFor(column)` and saves in `onDrop`, which gets the final column and index in the rendered list. (guard: review)
